# Os dados que você precisa

Oferecemos uma grande variedade de visualizações para seus dados de análises. Você pode escolher intervalos de tempo para a maioria das visualizações. Para dados de série temporal, você pode escolher a granularidade para visualizar os resultados (dia, semana, mês). A maioria das visualizações é ajustada ao fuso horário do relógio do seu computador.

![Uma captura de tela da visualização de Reproduções por Episódio de um podcast](/images/content/features/analytics-listens-by-episode.png)

Cada visualização de análises inclui uma explicação do que você está vendo e como interpretar os dados, para que você nunca fique sem contexto. Vamos até anotar seus gráficos para mostrar quando os episódios foram publicados. E, claro, você pode baixar qualquer visualização como CSV.

## Visualizações exclusivas

Veja quando seus ouvintes baixam episódios, a taxa relativa de crescimento dos episódios, a localização dos ouvintes e muito mais. Temos confiança de que oferecemos uma das maiores seleções — se não a maior seleção — de visualizações de análises entre todos os hosts de podcast. Além disso, os gráficos que fornecemos são cuidadosamente projetados para responder perguntas reais sobre seu podcast; eles não são só bonitos de se ver.

![Uma captura de tela da visualização de Crescimento de Reproduções por Episódio de um podcast, disponível com o complemento Análises Pro](/images/content/features/analytics-listen-growth-by-episode.png)

Com todo esse detalhamento vem alguma complexidade, mas não se preocupe: abaixo de cada gráfico há uma explicação dos dados, incluindo detalhes sobre o que está incluído e o que não está, e se os dados são ajustados ao fuso horário.

O Pinecast oferece 17 visualizações de análises para podcasts, 13 visualizações para episódios e 13 visualizações para redes de podcasts (disponíveis com nosso complemento Equipe). Você vai ter dificuldade para encontrar outro host que ofereça tantos dados com a mesma qualidade do Pinecast.

Você pode ver todos os detalhes de todas as nossas visualizações de análises [em nosso site de suporte](https://help.pinecast.com/article/158-analytics).
